## Editorial rationale
The Tamil Nadu Class 7 textbook uses 'திறவுகோல்' for dichotomous key, so this is not universally an incorrect Tamil term. In response to the user's preference, this edition instead uses a descriptive, purpose-based expression 'இருபிரிவு இனங்காணல் முறை', retaining English 'Dichotomous key' in parentheses. This Tamil rendering is editorial and NOT represented as an officially mandated textbook term.
